# MediBot AI
**Doctor in Your Language** — Team Weblaster · iQOO Hackathon 2026 · HealthTech · Bengaluru

A phone-first, multilingual AI health companion that turns any ₹7,000 Android
into a clinic: symptom triage in English, Hindi, Kannada & Tamil, severity
tags, one-tap 108 emergency escalation, nearby clinics, medicine reminders,
and an offline mode for zero-network areas.

## Live Demo
https://medibot-weblaster.netlify.app

## Features
- AI symptom chat in 4 Indian languages (Gemini API, parallel-race + 10s guarantee)
- Severity triage: Low / Moderate / High with color tags
- One-tap 108 ambulance escalation
- Nearby clinics with Call & Directions + filters (Nearest / Open / 24×7 / Top rated)
- Medicine reminders saved on-device (localStorage)
- Offline fallback mode — guidance works with no internet
- Night mode, city switcher, phone-first UI

## Tech Stack
HTML · Tailwind CSS · Vanilla JavaScript · Google Gemini API · Netlify

## Run Locally
1. Download `index.html`
2. Open in any browser (internet needed for fonts/AI)
